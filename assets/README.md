# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

### Pocket Fishing Noto Sans SC subsets

Used by the Pocket Fishing firmware (`main/CMakeLists.txt` compiles them;
`main/fish_fonts.c` selects them, with a Montserrat fallback used only for the
`LV_SYMBOL_*` battery icons).

| File | Size / bpp | Source weight | Coverage | Flash (.rodata) |
| --- | --- | --- | --- | ---: |
| [`fonts/fish_font_16.c`](fonts/fish_font_16.c) | 16 px / 4 | Regular | ASCII, punctuation, every UI string | 40,395 B |
| [`fonts/fish_font_24.c`](fonts/fish_font_24.c) | 24 px / 4 | Medium | ASCII, punctuation, every UI string | 83,677 B |
| [`fonts/fish_font_40.c`](fonts/fish_font_40.c) | 40 px / 4 | Medium | `FISH_LARGE_TEXT` only: reel prompt glyphs and the bite headline | 4,315 B |

- Source: Noto Sans SC 2.004, `Sans/SubsetOTF/SC/NotoSansSC-Regular.otf` (SHA-256
  `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`) and
  `NotoSansSC-Medium.otf` (SHA-256
  `7633f5a016d4dd95e685a69633d818aabc4644c4b08e26bd35b1b30c45ed5dda`) from
  <https://github.com/notofonts/noto-cjk/tree/Sans2.004> (commit
  `523d033d6cb47f4a80c58a35753646f5c3608a78`). The OTF files are not committed.
- License: SIL Open Font License 1.1, copied to
  [`fonts/NotoSansSC-OFL.txt`](fonts/NotoSansSC-OFL.txt). The generated bitmaps are a
  modified version and use their own names (no Reserved Font Name).
- Character inventory: [`tools/gen_fish_fonts.py`](../tools/gen_fish_fonts.py) collects
  every code point in string literals of `main/fish_*.c/.h`, adds printable ASCII and a
  fixed punctuation list, and writes `main/fish_ui_charset.h` for the boot-time glyph
  self-check. The 40 px font covers only `FISH_LARGE_TEXT` from `main/fish_fonts.h`.
- Converter: `lv_font_conv` 1.5.3 through `npx`, output compatible with LVGL 9.5.0.
  Regenerate after changing any UI string or catalog entry:

  ```bash
  mkdir -p ~/.cache/noto-sans-sc && cd ~/.cache/noto-sans-sc
  base=https://raw.githubusercontent.com/notofonts/noto-cjk/523d033d6cb47f4a80c58a35753646f5c3608a78
  curl -fLO "$base/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf"
  curl -fLO "$base/Sans/SubsetOTF/SC/NotoSansSC-Medium.otf"
  cd - && python3 tools/gen_fish_fonts.py --font-dir ~/.cache/noto-sans-sc
  ```

- Verification: `tests/test_fish_fonts.py` (part of `./tools/validate.sh --static`)
  parses the generated cmaps and fails when a UI string, catalog name, or large-prompt
  glyph is missing, with U+9F98 as a known-absent negative case.

### Pocket Fishing 8-bit pixel art

- Source: original art drawn procedurally in [`tools/gen_fish_sprites.py`](../tools/gen_fish_sprites.py)
  (shapes, a fixed 16-color palette, and an automatic 1 px ink outline). It was written for
  this repository and uses no third-party images.
- Integration: `main/CMakeLists.txt` runs the generator at build time and compiles its output
  from the build directory; the scaled arrays are not committed. `main/fish_sprites.h`
  declares the images, and the art order is read from `main/fish_catalog.c`, so a catalog
  entry without art fails the build.
- Format: native pixels scaled ×3 with nearest-neighbour sampling. Uncompressed RGB565 is
  used for the background and RGB565A8 for sprites; LVGL 9.5 draws both directly from Flash
  without decoding into RAM. Do not scale these images at runtime.

| Image set | Native → display size | Flash |
| --- | --- | ---: |
| Background (dusk sky, setting sun, hills, pond; horizon at y = 150; no clouds or waves) | 80 × 107 → 240 × 320 | 153,600 B |
| Catches, one per `FISH_ENTRIES` row | 32 × 20 → 96 × 60 | 172,800 B |
| Undiscovered silhouettes of the same catches | 32 × 20 → 96 × 60 | 172,800 B |
| Bait icons, one per `FISH_BAITS` row | 16 × 16 → 48 × 48 | 20,736 B |
| Three drifting clouds | 16 × 5, 11 × 4, 7 × 2 → ×3 | 3,726 B |
| Water waves: short, long, and medium crests in cream, light blue, and blue | 8 × 2, 14 × 2, 11 × 2 → ×3 | 3,564 B |

- Animation: `main/fish_ui.c` moves the clouds and the waves from right to left from one
  100 ms LVGL timer, always in whole art pixels (3 px) for a stepped 8-bit look. Clouds
  drift at about 2–3 px/s and waves at 3–6 px/s. Clouds and waves sit only in rows that
  are free of text on every page. The timer stops when the screen turns off.

- Regenerate the review sheet after changing the art:
  `python3 tools/gen_fish_sprites.py --preview assets/images/fishing-sprites-preview.png`.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.
